THE IMPLEMENTATIONS
IMPLEMENTATION 01VULNERABLE

Shell command

User input is concatenated into a command string. The shell interprets metacharacters such as &.

exec(commandString)
  • Shell interprets the string
  • Command chaining can occur
  • Timing can reveal hidden execution
IMPLEMENTATION 02SECURED

Argument execution

Input is validated and supplied as one argument. No shell is used to parse user-controlled text.

execFile("ping", args)
  • Strict hostname/IP validation
  • Separate argument vector
  • shell: false

The vulnerable endpoint is intentionally restricted to a fixed harmless demonstration payload. It is not a production design.

03

THE CONCEPT / CWE-78

Blind does not mean invisible.

In blind OS command injection, command output is not returned to the user. A time-based test can still reveal execution: if a harmless injected command adds a predictable delay, the HTTP response takes longer even though the command output remains hidden.

The mitigation demonstrated here is to avoid shell interpretation, validate input on the server, and execute the ping program with a separate argument array.
